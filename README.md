# Orbit Dashboard

Локальный MVP личной рабочей системы. Здесь можно добавлять задачи по сферам жизни, задавать срок, очередь и приоритет, смотреть колесо баланса и хранить историю действий.

## Запуск

1. Установите Node.js 22.13 или новее.
2. В папке проекта выполните `npm install`.
3. Запустите `npm run dev -- --hostname 127.0.0.1`.
4. Откройте `http://127.0.0.1:3000`.

API-ключи не нужны. ИИ и внешние действия в этой версии отключены.

## Проверки

- `npx oxlint app lib db --type-aware --type-check`
- `npm run build`

Проект рассчитан только на локальный доступ. Архитектура и границы следующего этапа описаны в `ARCHITECTURE.md`.
