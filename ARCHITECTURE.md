# Архитектурное решение: локальный дашборд Orbit

## Текущий этап

MVP, работающий только на локальном компьютере. Цель этапа — надёжный интерфейс управления задачами до подключения ИИ-агентов.

## Компоненты

- **Dashboard:** React/Vinext, адаптивный интерфейс в стиле AI Training Coach.
- **Backend API:** серверные route handlers `/api/tasks`, `/api/tasks/:id`, `/api/demo`.
- **Хранилище:** SQLite-совместимый D1; таблица хранит версионируемый снимок задачи и журнал событий.
- **Контроль действий:** предложение связано с задачей и её ревизией. Повторное или устаревшее решение отклоняется. В MVP одобрение только записывается; внешнее действие не выполняется.

## Модель задачи

Сфера и необязательное направление, описание, срок, номер очереди, приоритет, статус, история шагов, результат и опциональное предложение для подтверждения. Демо-записи изолированы от пользовательских.

## Следующий этап

Отдельный Python-сервис на OpenAI Agents SDK: классификатор/оркестратор → исследователь → генератор отчёта. Dashboard вызывает сервис через серверный API. Все инструменты с побочным эффектом возвращают предложение; исполнение разрешено только после серверной проверки явного подтверждения и идемпотентного ключа.

## Границы безопасности

Текущий API принимает запросы только с loopback-адреса и не предназначен для публикации. Перед облачным доступом обязательны аутентификация, разграничение владельцев, CSRF-защита, хранилище секретов, журнал неизменяемых действий и резервное копирование.
