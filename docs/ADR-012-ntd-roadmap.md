# ADR-012 — Реестр НТД и сценарии рисков

MVP, 2026-09-04. Основание: владелец поручил подключить загруженную дорожную карту Excel и компактно обновить перечень рисков.

Используется существующий защищённый читатель XLSX (fflate/@xmldom, без новых runtime-зависимостей). Добавляется опциональное представление ячеек для импорта именованных таблиц. Оригинал не меняется. Реестр из листа «01_База НТД» и сценарии «05_Наряды-допуски» сохраняются с именем файла, SHA-256, датой импорта, координатами и датами проверки, указанными автором таблицы.

Отдельная таблица Supabase `orbit_ntd_libraries`: добавление версий, RLS владельца, без публичного доступа и без service_role. Импорт через авторизованный API ограничен 2,5 МБ. Конкурентная версия отклоняется; прежний импорт не перезаписывается. Локальный режим использует временную память, как остальной MVP. Excel не синхронизируется автоматически с Vercel.

В ТЗ пять прежних рисков остаются в прежних ключах. Дополнительные сценарии имеют отдельные стабильные ID НД-01…НД-31 и необязательное поле `permitRisks`; отсутствие значения означает «Уточнить». Пустое новое поле не добавляется в старые снимки: существующие утверждения не должны меняться только от обновления интерфейса. Галочка означает наличие сценария, отдельное «Нет» — явное исключение. Переключение сценария не делает нормативного вывода и не меняет автоматически базовые риски, состав приложений или документы.

Это справочный навигатор, не полные нормативы и не проверка актуальности/обязательности. Метки и основания отображаются как сведения автора Excel. Полные тексты, нормативный агент и автоматическая проверка разделов не подключаются на этом этапе. Встроенные в Excel правила не становятся исполняемыми инструкциями; внешние ссылки не открываются сервером.

Проверки: импорт/схема/URL/повтор/конфликт/изоляция, совместимость ТЗ, сохранение рисков, поиск и мобильный вид. Откат: revert кода; новые записи библиотеки и таблица сохраняются, удаления не требуются. Перед возвратом к старому ПО выгрузить задачи с новыми сценариями, т.к. прежний парсер их не знает.
