# ADR-010 — Папка и ссылка на исходные данные проекта

Статус: принято для MVP, 2026-09-04. Запрос владельца — привязка папки рабочих проектов и ссылки к ППР. Существующий стек и правила передачи в ИИ сохраняются.

- `WorkProject.sourceFolderUrl` — необязательная HTTPS-ссылка, сохраняется в существующем payload задачи с проверкой ревизии и прав владельца. Это ссылка для открытия пользователем, не разрешение серверу обходить произвольные сайты. Пароли в URL запрещены. Ссылка не передаётся модели и не меняет утверждённое содержание ТЗ.
- Локальный путь остаётся существующим полем `brief.workingFolder`. Vercel не получает доступ к диску компьютера. На локальном сервере каталог доступен только внутри разрешённого корня, включая проверку реальных путей и ссылок файловой системы.
- В исходных данных появляется выбор папки через браузер, вложенные пути, поиск и явный выбор файлов. Содержимое не читается/не отправляется при выборе папки. «Прочитать» использует существующий API разбора, передача выбранного текста SOL — отдельное подтверждение.
- Форматы и лимиты текущего разбора сохраняются: DOCX/PDF/TXT, 2,5 МБ на файл, до 4 файлов и 2,8 МБ на пакет. Остальные файлы видны с причиной недоступности; ничего не конвертируется и не отбрасывается молча. Крупные PDF, XLSX, DWG и OCR — следующие самостоятельные этапы.
- Используется встроенный HTML `webkitdirectory` / `File.webkitRelativePath`, без зависимости, туннеля и нового облачного хранилища. Для браузеров без выбора папки оставлен выбор отдельных файлов. Документация: https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/webkitdirectory . Новые библиотеки и лицензии не добавляются.
- Список выбранных файлов живёт в текущей вкладке. Ссылка и путь синхронизируются; автоматической синхронизации содержимого папок нет. Оригиналы не изменяются.
- Откат: предыдущий коммит e74036f. Миграция БД не требуется, новое поле необязательное.
