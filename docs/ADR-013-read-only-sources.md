# ADR-013 — Исходники только для чтения, без постоянных копий

Дата: 2026-09-04. Стадия: MVP. Основание: прямое указание владельца.

## Проблема и решение
Повторный анализ создавал записи-дубли: registerFiles использовал file- + SHA-256 (69 символов), а hydrateWorkProject сокращал id до 60. Теперь полный валидный id сохраняется, прежний сокращённый распознаётся без изменения старых записей. В одном запросе одинаковые байты разбираются один раз; конфликтующее назначение отклоняется. Одинаковое имя при разном содержимом не является основанием для объединения.

Исходники и шаблоны больше не записываются в IndexedDB: только выбранный File текущего окна и временные буферы обработки. Кэш остаётся для собранных/исправленных Word-версий. Локальный источник явно открывается с flags: r; файловые маршруты имеют только GET. API анализа принимает байты, не путь для записи. Сборка Word возвращает новый документ и не меняет шаблон.

Использованы существующие Node.js createHash/createReadStream, File и IndexedDB; новых зависимостей или инфраструктуры нет. Постоянные файловые handles и локальный агент не добавляются: это отдельная задача с другой моделью доступа.

## Ограничения
Vercel не читает D: напрямую. После закрытия страницы и на другом устройстве документы выбираются снова. Внешнее изменение файла требует повторного выбора обновлённого оригинала. Временные байтовые буферы необходимы для передачи/разбора; цитаты остаются в истории. Старые дубли/копии не удаляются автоматически. Реальные исходники и задачи при разработке не менялись.

## Проверки и откат
29 unit-тестов, lint/build, изолированный API: повторный и переименованный источник, полный id после загрузки БД, старый id, конфликт назначения, неизменность байтов/mtime/состава тестовой папки, отказ POST/PUT/PATCH/DELETE для файловых маршрутов. Сборка DOCX не меняет исходный массив байтов. Реальный SOL не запускался.

Миграция не требуется. База отката — a193c3d; полный откат возвращает дефект дублей, поэтому предпочтителен адресный откат. Пакет не удаляет исходники или историю.
