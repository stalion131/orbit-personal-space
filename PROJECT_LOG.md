# Журнал проекта

## 2026-08-31 — Dashboard MVP

- Создан локальный дашборд задач с шестью сферами колеса баланса и согласованными подкатегориями.
- Добавлены срок, очередность, приоритет, поиск, фильтры, история шагов, экспорт и ручное завершение.
- Добавлен безопасный деморежим подтверждений; он не вызывает LLM, поиск, почту, бронирование или оплату.
- Подключено устойчивое локальное хранение и конкурентный контроль по ревизии.
- Стиль адаптирован по `D:\Projects\ai-training-coach`: navy-фон, градиентные панели, оранжевые действия и цветовые акценты сфер.
- Проверено: целевой lint/typecheck, production build, чтение шести сфер из базы, сроки/приоритеты у всех демо-задач, переход `ожидает → подтверждение → решение`, отклонение устаревшего решения.
- Зависимости: high/critical уязвимости устранены. Остались 4 moderate в dev-зависимости Drizzle Kit; предложенное npm-исправление понижает пакет с несовместимым major и поэтому не применено.
- Ограничение: это локальный MVP без аккаунтов и ИИ-агентов. Не публиковать до добавления аутентификации и модели доступа.

Следующий рекомендуемый шаг: подключить минимальный Python-оркестратор на OpenAI Agents SDK без инструментов с побочными эффектами.

## 2026-08-31 — Пользовательские задачи

- Полностью удалены демонстрационные записи из локальной базы.
- Добавлены 17 пользовательских задач по сферам «Работа», «Личные задачи» и «Встречи».
- Добавлены направления «Квартира» и «Сфера строительства / Текущие проекты», а также новая сфера «Встречи».
- Очередность соответствует порядку исходного списка. Для задач без указанной даты срок оставлен пустым.
- Ближайшие задачи на 1 и 4 сентября отмечены критическими; остальные получили консервативный приоритет по срочности.

## 2026-09-01 — Подготовка облачной и мобильной версии

- Добавлен режим Supabase Auth/Postgres с серверной проверкой JWT и RLS по владельцу; `service_role` не используется.
- Добавлена SQL-миграция с явными grants и отдельными политиками select/insert/update.
- Локальный D1 сохранён как режим разработки и отката; удалённый доступ к нему по-прежнему запрещён.
- Добавлен валидируемый импорт `orbit-tasks-v1`. Локально проверено: 17 задач до импорта, 17 принято, 17 осталось после идемпотентного повторного импорта.
- Добавлены manifest, три PWA-иконки, безопасный service worker и инструкции установки на Android/iPhone. API и страницы с задачами не кэшируются.
- Исправлено горизонтальное переполнение на мобильной ширине; при 375 px `scrollWidth` совпадает с `clientWidth`.
- Проверено: production build, lint, локальная загрузка 17 задач, блокировка чужого Origin (403), manifest/service worker (200), мобильный интерфейс без ошибок консоли.
- Ограничение: live Supabase/RLS и production-ссылка ещё не проверены — нет отдельного проекта/ключей и решения владельца по размещению данных. Hosted Supabase не имеет российского региона; реальные задачи туда не передавались.

Следующий шаг: владелец выбирает допустимое размещение. После выбора — создать отдельный проект, выполнить миграцию, проверить изоляцию двумя аккаунтами, установить runtime-переменные Sites и развернуть owner-only версию.
